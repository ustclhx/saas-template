# Proposal

## Why

衍生项目需要「结果分享卡片」：用户把一次结果（报告、生成内容等）分享到社交平台时，预览图要显示这次结果本身的标题和要点，而不是站点通用图。模板现在只在构建期为公开页面生成静态 OG 图（`apps/web/src/features/seo`，satori + resvg-wasm，只在 Node 构建期运行）。运行时没有渲染能力，也没有「哪些结果允许公开分享」的机制，所以衍生项目只能各自自建，或者把私有结果的 ID 直接放进公开 URL。需求来源：xuanxue 基础需求 R5.3（`~/.claude/codex-specs/saas-template/2026-11-10-foundation-from-xuanxue.md`）。

## What Changes

- **访问控制归项目**：模板不建分享表，也不规定资源归属与撤销流程。项目注册「解析函数」：输入令牌，返回所属空间、分享时间、可选到期时间和展示数据，令牌无效时返回空。模板提供生成随机令牌的工具（≥128 位），以及项目撤销或删除资源时调用的失效函数。
- **默认 90 天到期**：项目没给到期时间时，按分享时间加 90 天计算；项目可以按类型修改天数或设为永不过期。到期后卡片地址和分享页都返回 404，缓存时长不超过剩余有效期。
- **分享卡片注册**：衍生项目按「卡片类型」注册：解析函数、展示数据摘要、版式（受限的 JSX，只用分享卡片主题里的 token）、版式版本号、替代文本、分享页标题与描述。模板自带一个中性的示例类型，只在测试与 `/dev/ui` 中注册。
- **运行时渲染路由**：`GET /share-card/<类型>/<令牌>.png` 按需生成 1200×630 PNG。
  - 令牌格式不符、解析为空、已失效或已到期时返回 404，不返回任何内容。
  - 生成结果存入持久存储（R2，自托管为对象存储），并经边缘缓存。
  - 地址包含版式版本和数据摘要，内容一变地址就变，可以长期缓存。
  - 缓存未命中才查库，符合 Neon 成本基线。
- **字体与主题**：
  - 西文字体随渲染器打包。
  - 中日韩字形用完整字体，从静态资源按需加载，文本含 CJK 时才加载，同一实例内只加载一次，不打进 Worker 包。
  - 卡片颜色和圆角来自 `@saas/ui` 的 token。项目品牌在项目自有的主题文件里覆盖，与 `brand.css` 对应。
- **通用分享页**：`/s/<类型>/<令牌>` 显示卡片图片、标题、描述和站点入口，带 `noindex`。项目可以按类型关闭，改用自建页面。
- **页面元数据**：元数据工具输出 `og:image`、`twitter:image`（`summary_large_image`）与替代文本，指向分享卡片地址；通用分享页和项目自建页面共用。
- **保持不变**：构建期静态分享图保持现有行为，仍是没有封面的公开页面的默认图。卡片版式工具与构建期生成器共用同一套渲染代码。
- **包体积约束**：渲染器只在分享卡片路由中懒加载，首页包检查与其他路由的冷启动不受影响。
- **先做可行性验证**：实施前先在 staging 量化包体积增量、冷启动 CPU（含加载 CJK 字体）、内存与渲染耗时，达到 design 中的阈值才继续，否则按 design 的备选方案调整。
- **设计关卡**：示例卡片、默认卡片版式和通用分享页先在 Design 画布出稿，经使用者确认后再实现。
- **不在本变更**：
  - 各项目的分享表、分享按钮与撤销界面（属于项目业务）；
  - 卡片内的图表、二维码等复杂图形；
  - 动态 GIF 或视频；
  - 构建期静态图改为运行时生成。

## Capabilities

### New Capabilities
- `share-cards`：项目解析与令牌工具、默认到期、失效、卡片类型注册、运行时渲染路由、缓存、通用分享页、元数据，以及防滥用。

### Modified Capabilities
- `account-deletion`：删空间（含删号时的个人空间）的清理范围增加该空间已生成的分享卡片图片。

## Impact

- **代码**：
  - 新增 `apps/web/src/features/share-cards/`：注册表、令牌与失效工具、渲染、缓存、元数据工具、示例卡片；
  - 新增路由 `/share-card/*` 与 `/s/*`；
  - `packages/ui` 导出分享卡片可用的 token 值；
  - `apps/web/scripts/og-images.ts` 改为复用共享的渲染代码。
- **数据库**：无迁移。
- **依赖**：不新增依赖，继续使用已安装的 `cf-workers-og`、`satori`、`@resvg/resvg-wasm`。Worker 包增加 resvg 与 satori 的 WASM（约 2.6 MB，未压缩），需要在验证阶段确认部署体积。
- **存储与缓存**：使用现有 `FILES`（R2）绑定，新增 `share-cards/` 前缀；Cloudflare 上用 Cache API，自托管用对象存储加 HTTP 缓存头。
- **路由与 SEO**：新增公开路由 `/share-card/*` 与 `/s/*`。robots 放行（部分社交平台的抓取器遵守 robots），响应带 `X-Robots-Tag: noindex`，不进站点地图。
- **衍生项目**：同步后得到注册接口；没有注册卡片类型的项目没有行为变化。注册的项目自建分享表，并在撤销与清理时调用失效函数。
- **文档**：`docs/` 中的 SEO / 分享说明、升级说明，以及 `new-page` / `new-module` 技能中的分享卡片接入步骤。
