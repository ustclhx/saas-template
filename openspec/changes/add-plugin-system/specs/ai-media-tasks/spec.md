# Spec Delta

## ADDED Requirements

### Requirement: 媒体能力由媒体插件提供
图片与视频生成任务（创建页、任务列表与详情、任务接口、公共 API 任务接口、服务商回调、后台执行与预扣清理）SHALL 只在启用媒体插件时存在。启用图片或视频种类而未启用媒体插件 MUST 使构建失败。未启用时上述页面与接口返回 404，导航不显示媒体入口，jobs 不注册媒体任务。

#### Scenario: 未启用媒体插件
- **WHEN** 项目关闭图片与视频且未启用媒体插件
- **THEN** `/app/<空间>/media/new` 与 `/api/webhooks/media/fal` 返回 404，构建产物不含媒体执行代码

#### Scenario: 种类开关与插件不一致
- **WHEN** 项目开启图片生成但未启用媒体插件
- **THEN** 构建失败并提示在 `plugins` 中加入媒体插件

#### Scenario: 迁移后行为不变
- **WHEN** 启用媒体插件的项目提交图片任务
- **THEN** 预扣、执行、转存、结算与通知的行为与迁移前一致
