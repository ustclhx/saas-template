# Proposal

## Why

衍生项目要大改报告提示词（xuanxue 提示词 v4，新增流年等章节），现在只能人工抽检：改一次提示词，看不出哪些样本变好、哪些变差，也没有办法离线重复同一次对比。模板里没有提示词定义、版本号或评测工具，各项目只能自建。需求来源：xuanxue 基础需求 R6（`~/.claude/codex-specs/saas-template/2026-11-10-foundation-from-xuanxue.md`）。

## What Changes

- **提示词定义与版本约定**：
  - `@saas/ai` 新增业务无关的提示词定义工具：标识、版本、system、用户消息渲染、期望章节、输出上限；导出 `promptVersion`（`<标识>@<版本>`）与内容摘要。
  - 版本不可变：内容一改就必须新建版本。每个评测套件带一个版本锁文件，评测运行时发现「同一版本、内容不同」直接报错。
  - 生成记录保存 `promptVersion`：模板只写成文档约定，并给出项目自有生成表的建议列；`ai_message` 不加列（理由见 design D3）。
- **评测工具 `pnpm eval:prompts --suite <name>`**（新包 `packages/evals`，只供命令行使用，任何 app 或运行时包不得依赖）：
  - 输入：固定样本集（JSON 输入 + 期望约束）与一个或多个提示词版本；
  - 生成：默认用录制数据回放，离线、零费用；真实模型须显式 `--live` 并给出 `--budget-usd`；`--record` 用真实模型生成并写回放录制；
  - 确定性检查（可插拔）：章节齐全、长度区间、禁用词与正则、语言与字形（含简繁误用）；
  - LLM 评委：评分标准由项目提供，评委模型单独配置，输出各项分数与理由；回放模式同样回放评委结果；
  - 报告：写入 `EVIDENCE_DIR`（不进仓库），含逐样本检查、分数、用量与估算费用；可与基线版本或上一份报告对比，回退超过阈值时以非零码退出。
- **预算保护**：`--budget-usd` 是美元上限，按套件声明的每模型单价与 token 估算（输入估算 + 最大输出）。任何一次调用（含评委）在发出前若可能超过上限，就停止，剩余样本记为「预算跳过」。
- **示例套件**：模板自带一个中性示例套件（两个提示词版本、中英文样本、示例评分标准与录制数据），作为包内单测离线跑通，覆盖回放、检查、评委、基线对比与预算逻辑。
- **不进默认 CI 的真实调用**：根脚本不在 turbo `test` 中；`CI` 环境下拒绝 `--live` / `--record`。
- **项目自有目录**：衍生项目的套件放在根目录 `evals/<suite>/`，模板不在该目录交付任何文件，template-sync 不会覆盖。
- **不在本变更**：
  - 线上 A/B、灰度或按流量自动切换提示词版本；
  - 评测结果入库或后台页面；
  - 项目自己的提示词迁移（xuanxue v4 由项目做）；
  - 多轮对话或工具调用类提示词的评测（本次只覆盖单次文本生成）。

## Capabilities

### New Capabilities
- `prompt-evals`：提示词定义与版本不可变约定、评测套件与样本、回放 / 真实 / 录制三种模式、美元预算上限、可插拔确定性检查、LLM 评委、报告与基线对比、退出码，以及项目自有套件目录。

### Modified Capabilities
（无。`template-sync` 现有「衍生项目自有配置不被模板覆盖」要求已涵盖项目自有路径；本变更只在实现上登记 `evals/` 目录。）

## Impact

- **代码**：
  - 新增 `packages/ai/src/text/prompt.ts`（定义工具与摘要，无业务、无新依赖）；
  - 新增 `packages/evals`：套件加载、运行器、检查、评委、预算、回放与录制、报告、命令行入口、示例套件；
  - 根 `package.json` 新增 `eval:prompts` 脚本与 `@saas/evals` 开发依赖。
- **依赖**：`packages/evals` 只用已有的 `ai`、`zod`、`vitest`；简繁检查用仓库内的小型字表，不引入转换库。
- **依赖边界**：`scripts/check-deps` 增加规则：除根目录外，任何 app 或 package 不得依赖 `@saas/evals`。
- **数据库**：无迁移。
- **生成器与同步**：`template-release` 检查确认模板不在 `evals/` 交付文件；生成器原样复制 `packages/evals`。
- **文档**：`docs/06-ai.md` 新增「提示词版本与评测」一节；`new-module` 技能加入 AI 生成功能的提示词版本与评测步骤；下一版本升级说明。
- **衍生项目**：同步后无行为变化。需要评测时自建 `evals/<suite>/`，并在自有生成表中保存 `promptVersion`。
