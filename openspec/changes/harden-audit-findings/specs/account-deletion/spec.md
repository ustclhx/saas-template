# Spec Delta

## MODIFIED Requirements

### Requirement: 账号匿名化
删除账号后，系统 SHALL 使该账号无法再登录，清除其姓名、头像、偏好、密码哈希、OAuth 令牌、会话、两步验证与 API Key，并将邮箱替换为不可投递的占位值。系统 SHALL 永久删除该用户在其所在团队空间中创建的对话、消息与媒体任务记录，该用户的站内通知，以及 newsletter 与 waitlist 中该邮箱的记录；个人空间的内容按「删除团队空间」的保留期规则删除。团队空间中由该用户上传、属于空间共享资产的文件 SHALL 保留。系统 MUST 保留指向该账号的财务记录（付款、退款、订阅、积分账本与预扣、支付通知）与审计记录，审计记录中的邮箱、姓名等个人信息 MUST 被去除。

#### Scenario: 删号后尝试登录
- **WHEN** 已删除账号的原邮箱和密码尝试登录
- **THEN** 登录失败

#### Scenario: 删号后的审计记录
- **WHEN** 管理员查看该用户过去的积分流水与审计日志
- **THEN** 记录仍然存在，用户显示为已删除用户，不显示原邮箱和姓名

#### Scenario: 删号后团队空间中的对话
- **WHEN** 用户在一个仍存在的团队空间中有对话与媒体任务，随后删除账号
- **THEN** 这些对话、消息与媒体任务记录被永久删除，团队空间的积分流水仍完整

#### Scenario: 删号后的订阅列表
- **WHEN** 用户订阅了 newsletter 并加入过 waitlist，随后删除账号
- **THEN** newsletter 与 waitlist 中不再有该邮箱的记录

### Requirement: 删除团队空间
只有 owner SHALL 能删除团队空间；删除后该空间的成员 MUST 立即失去访问权限，未处理的邀请与该空间的 API Key MUST 作废，空间内容数据在保留期（默认 30 天）后被永久删除，保留期内平台管理员可以恢复。永久删除的范围 SHALL 包括对话、消息、媒体任务、文件及存储对象、通知与邀请；MUST 保留财务记录与审计记录。个人空间随账号删除进入同一保留期规则。

#### Scenario: 删除后成员访问
- **WHEN** owner 删除团队空间后，原成员访问该空间
- **THEN** 返回 404

#### Scenario: 保留期内恢复
- **WHEN** 平台管理员在保留期内恢复该空间
- **THEN** 空间及其内容恢复可访问，删除时的 owner 恢复为 owner，其他成员需要重新邀请

#### Scenario: 保留期结束
- **WHEN** 保留期结束后清理任务运行
- **THEN** 该空间的对话、消息、媒体任务、文件及存储对象被永久删除，数据库中不再有这些记录，财务与审计记录保留
