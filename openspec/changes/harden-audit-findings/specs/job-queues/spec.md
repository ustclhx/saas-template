# Spec Delta

## ADDED Requirements

### Requirement: Cloudflare 事件队列死信
Cloudflare 目标的事件队列（计费后处理与运营通知）SHALL 配置死信队列；消息达到最大投递次数或遇到不可重试错误后 SHALL 进入死信，由死信消费者持久记录消息标识、原队列、尝试次数、失败原因与时间并发出运营告警，MUST NOT 仅记录日志后丢弃。认证邮件队列维持不配置死信的现有行为。

#### Scenario: 事件处理持续失败
- **WHEN** 一条计费后处理事件连续 6 次投递都失败
- **THEN** 该消息进入死信，数据库中可查到它的标识、原队列、尝试次数与失败原因，运营渠道收到告警
