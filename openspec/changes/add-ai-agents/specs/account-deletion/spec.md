# Spec Delta

## ADDED Requirements

### Requirement: 清理 agent 对话
删号与删空间的 AI 内容清理 SHALL 同时清除被清理 agent 对话的实例内消息数据与轮次记录；清理 MUST 幂等，实例清理失败时可重试且不阻塞其他数据的清理，最终不残留可访问的对话内容。删号 SHALL 立即清理该用户的 agent 对话（个人空间与团队空间）；删团队空间 SHALL 与其他空间内容一致，在保留期内保留 agent 对话以便恢复，保留期结束后再清理，实例数据在 30 天内被清除。

#### Scenario: 删除团队空间中的 agent 对话
- **WHEN** 团队空间保留期结束，空间中有 agent 对话
- **THEN** 轮次记录与对话行被删除，对话实例数据在 30 天内被清除，其他空间不受影响

#### Scenario: 保留期内恢复团队空间
- **WHEN** owner 删除团队空间后，平台管理员在保留期内恢复该空间
- **THEN** 删除期间该空间的 agent 对话返回 404，恢复后原 owner 的 agent 对话与轮次记录完整可访问

#### Scenario: 删号后的 agent 对话
- **WHEN** 用户在个人空间与团队空间中都有 agent 对话，随后删除账号
- **THEN** 这些对话、轮次记录与实例数据立即被清理，团队空间其他成员的对话不受影响

#### Scenario: 实例清理暂时失败
- **WHEN** 清理时某个实例调用失败
- **THEN** 其余对话照常删除，失败的实例在其下一次自检（30 天内）时被清空
