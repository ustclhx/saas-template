# Spec Delta

## Purpose

提供可调用工具、多步执行、可人工确认的 AI agent 对话，计费、权益、限流与租户隔离规则与文本对话一致；仅在 Cloudflare 部署且启用 agents 插件时可用。

## ADDED Requirements

### Requirement: Agent 对话归属
空间成员 SHALL 能创建、查看、删除自己的 agent 对话；对话内容 MUST 只对创建者可见。未登录访问返回 401，访问不属于自己的对话（包括同空间其他成员、已退出空间的成员）返回 404。

#### Scenario: 他人连接对话
- **WHEN** 同一空间的另一成员用对话 ID 建立连接或发送请求
- **THEN** 返回 404，对话实例未被访问

#### Scenario: 退出空间后
- **WHEN** 用户被移出空间后继续向该空间的 agent 对话发送消息
- **THEN** 请求被拒绝，不调用模型、不预扣积分

#### Scenario: 伪造身份头
- **WHEN** 客户端请求携带自定义的身份请求头
- **THEN** 这些头被丢弃，身份只取自站点会话

### Requirement: 每轮调用前检查
用户每发送一条消息开始一轮执行前，系统 SHALL 依次检查成员资格、模型权益且模型支持工具调用、限流、欠费与余额；任一不满足 MUST 拒绝并返回与文本对话相同的可区分错误，且不调用模型。

#### Scenario: 余额不足
- **WHEN** 余额不足以支付本轮预扣
- **THEN** 请求被拒绝并提示充值，模型未被调用

#### Scenario: 模型不支持工具
- **WHEN** 所选模型未标记支持工具调用
- **THEN** 请求被拒绝并提示模型不可用

### Requirement: 多步工具执行
一轮执行 SHALL 允许模型多次调用 agent 定义中列出的工具，并在达到最大步数或模型给出最终回复时结束。agent 只能调用其定义列出的工具；工具的数据访问 MUST 限定在当前空间。

#### Scenario: 调用工具后回答
- **WHEN** 用户请求需要工具结果才能回答的问题
- **THEN** 界面依次显示工具调用及其结果，最后显示模型回复

#### Scenario: 达到步数上限
- **WHEN** 模型持续调用工具达到最大步数
- **THEN** 本轮结束，界面提示已达上限，按实际用量结算

### Requirement: 人工确认
标记为需要确认的工具 SHALL 在执行前暂停并向用户展示工具名与参数；用户批准后才执行，拒绝时 MUST 不执行并把拒绝告知模型继续本轮。确认超时未处理的调用按过期处理，本轮按已产生用量结算。

#### Scenario: 拒绝执行
- **WHEN** 用户拒绝一个需要确认的工具调用
- **THEN** 工具未执行，模型收到拒绝结果并继续回复

#### Scenario: 确认超时
- **WHEN** 等待确认超过预扣有效期
- **THEN** 该调用标记为过期，预扣按已产生用量结算，不遗留未结算预扣

### Requirement: 按轮预扣与结算
每轮开始 SHALL 按步数上限预扣积分（不超过配置的单轮上限），结束后按实际用量结算，超额适用现有超额容忍与欠费规则；用户停止、断线或执行中断时 MUST 按已记录的用量结算，没有可见输出的失败按现有失败退款规则处理。同一轮因恢复而重复执行 MUST NOT 重复预扣或重复扣费。工具自身产生的费用按该能力自己的规则另行计费。

#### Scenario: 正常完成
- **WHEN** 一轮执行正常完成
- **THEN** 用量页出现一条本轮消耗流水，金额与实际用量和定价快照一致，预扣被释放

#### Scenario: 中途停止
- **WHEN** 用户在第二步时点击停止
- **THEN** 已显示的内容保留，按已记录用量结算

#### Scenario: 实例恢复
- **WHEN** 执行中实例被驱逐后恢复并继续同一轮
- **THEN** 只有一次预扣与一次结算

#### Scenario: 异常遗留
- **WHEN** 一轮因故障停留在执行中且预扣已过期
- **THEN** 后台清理按最后用量检查点结算并把轮次标记为终态

### Requirement: 断线续流
对话 SHALL 在客户端断线重连后继续显示进行中的回复，已完成的消息在重新打开对话时完整显示。

#### Scenario: 刷新页面
- **WHEN** 回复生成过程中用户刷新页面
- **THEN** 重新打开后继续显示该回复直至完成

### Requirement: 异步工具结果
返回长任务的工具 SHALL 立即给出任务已提交的结果；任务完成或失败后，结果 MUST 写回原对话，默认不自动开始新一轮模型调用。

#### Scenario: 生成任务完成
- **WHEN** agent 提交的媒体任务完成
- **THEN** 对话中出现任务结果，且未产生新的模型调用费用

### Requirement: 仅 Cloudflare 目标
agent 能力 SHALL 只在 Cloudflare 部署且启用 agents 插件时存在；未启用或 selfhost 部署时 agent 页面与 `/agents/` 路径返回 404，导航不显示入口。

#### Scenario: selfhost 部署
- **WHEN** selfhost 部署访问 agent 页面
- **THEN** 返回 404

### Requirement: 对话保留期
agents 插件 SHALL 提供可选的对话保留期配置，默认关闭。开启后，超过保留天数没有新消息的 agent 对话 MUST 连同实例数据与轮次记录一起删除，删除语义与用户手动删除对话一致；清理 MUST 复用现有清理 Cron，不新增定时任务，且只删除保留期已到的对话。

#### Scenario: 默认关闭
- **WHEN** 项目未配置保留期
- **THEN** agent 对话不会因无活动而被自动删除

#### Scenario: 超过保留期
- **WHEN** 保留期设为 90 天，某对话最后一条消息在 91 天前
- **THEN** 下一次清理后该对话从列表消失，之后访问返回 404，实例存储被清空

#### Scenario: 执行中的轮次
- **WHEN** 对话已超过保留期但仍有 running 状态的轮次
- **THEN** 本次清理跳过该对话，待轮次结算后再处理
