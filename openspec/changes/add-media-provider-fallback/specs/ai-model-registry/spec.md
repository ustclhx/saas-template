# Spec Delta

## ADDED Requirements

### Requirement: 备用模型配置
管理员 SHALL 能为文本、图片或视频模型按顺序配置至多 2 个备用模型，备用模型 MUST 已登记、与主模型同类型、不是主模型本身，且服务商互不相同；可为每个备用模型声明参数改名映射。
保存时系统 MUST 校验兼容性，不满足时拒绝保存并指出原因：媒体模型的主参数 schema 每个字段经映射后都能被备用 schema 接受（类型一致，枚举为备用的子集）；主文本模型带「支持工具调用」时，备用 MUST 也带此标记。

#### Scenario: 配置跨服务商备用
- **WHEN** 管理员为 fal 上的 Seedream 模型配置 Replicate 上的 Seedream 模型为第一备用，参数完全兼容
- **THEN** 保存成功，模型详情按顺序显示备用模型

#### Scenario: 参数不兼容
- **WHEN** 主模型的 `aspect_ratio` 允许 `21:9`，备用模型的同名参数不允许该值
- **THEN** 保存被拒绝，错误指出 `aspect_ratio` 不兼容

#### Scenario: 参数改名
- **WHEN** 主模型参数为 `image_size`，备用模型对应参数为 `size`，管理员声明映射 `image_size → size`
- **THEN** 校验按映射后的字段进行，兼容即保存成功

#### Scenario: 文本备用缺少工具能力
- **WHEN** 主文本模型支持工具调用，管理员选择一个不支持工具调用的文本模型作为备用
- **THEN** 保存被拒绝，提示备用模型缺少工具调用能力

#### Scenario: 备用链不成环
- **WHEN** 管理员把某模型自己，或与主模型同服务商的模型设为备用
- **THEN** 保存被拒绝

### Requirement: 备用模型不影响用户可见性与价格
备用模型 SHALL 只在服务端切换时使用：用户的模型列表、权益判断、预计消耗与扣费 MUST 只依据主模型；备用模型即使已停用或对该空间不可见，也 MAY 作为备用使用，但被删除时 MUST 自动从所有备用链中移除。

#### Scenario: 备用模型对用户隐藏
- **WHEN** 备用模型已停用，且不在该空间的套餐模型列表中
- **THEN** 用户在模型选择器中看不到它，主模型发生切换时仍可使用它执行

#### Scenario: 删除被引用的备用模型
- **WHEN** 管理员删除一个被其他模型列为备用的模型
- **THEN** 该模型从这些备用链中移除，主模型其余配置不变
