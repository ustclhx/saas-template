# Spec Delta

## ADDED Requirements

### Requirement: 文本备用模型切换
文本调用（对话回复、后续问题建议、agent 的每一步）在服务商返回任何输出之前遇到服务商侧失败（服务商未配置、限流、服务端错误、鉴权失败、网络中断）时，系统 SHALL 按备用顺序改用下一个可用的备用模型，用户无需重试。
已输出内容后发生的失败 MUST NOT 切换模型，按现有重试与续写规则处理；请求本身被拒（如输入过长、内容策略）MUST NOT 切换。

#### Scenario: 主模型限流
- **WHEN** 用户发起对话，主模型服务商返回限流错误，主模型配置了其他服务商的备用模型
- **THEN** 回复由备用模型生成并正常显示，用户只看到一次回复

#### Scenario: 已开始输出后出错
- **WHEN** 主模型已输出部分文字后连接中断
- **THEN** 不切换到备用模型，按现有规则重试或续写

#### Scenario: agent 中途某一步
- **WHEN** agent 运行到第 3 步时主模型服务商返回 5xx，且该步尚无输出
- **THEN** 该步改由备用模型执行，agent 继续后续步骤

#### Scenario: 全部候选失败
- **WHEN** 主模型与所有备用模型在输出前都失败
- **THEN** 本次调用按现有失败规则结束并退回预扣

### Requirement: 文本切换的计费与记录
文本调用切换到备用模型后，预扣、token 上限与结算 MUST 仍按主模型的定价快照；失败尝试 MUST NOT 向用户收费。系统 SHALL 记录实际生成回复的模型，供后台查看。

#### Scenario: 备用模型单价更高
- **WHEN** 对话切换到单价更高的备用模型完成回复
- **THEN** 用户按主模型价格结算

#### Scenario: 后台查看实际模型
- **WHEN** 管理员查看一条由备用模型生成的回复或 agent 轮次
- **THEN** 能看到主模型与实际生成所用的模型
