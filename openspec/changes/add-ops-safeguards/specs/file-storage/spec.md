## ADDED Requirements

### Requirement: 对象存储临时错误重试
对象存储的写入与删除遇到平台文档列为临时性的错误（内部错误、服务暂不可用、客户端断开、网络连接中断）时，系统 SHALL 以带抖动的指数退避有限次重试（总尝试不超过 3 次）；不可重试的错误（对象不存在、前置条件不满足、超出大小、鉴权与桶配置错误、同键写入过快）MUST NOT 重试。请求体为不可重放的流时 MUST NOT 在存储层重试。重试耗尽或不可重试时 SHALL 返回统一的「存储暂不可用」业务错误（503），日志记录错误码与尝试次数且不含对象键中的用户数据。Node 目标 SHALL 使用 S3 客户端自身的有限重试，不叠加第二层重试。

#### Scenario: 一次内部错误后成功
- **WHEN** 第一次写入 R2 返回内部错误，第二次成功
- **THEN** 调用方得到成功结果，日志记录一次重试

#### Scenario: 同键写入过快
- **WHEN** R2 返回同键写入限流错误
- **THEN** 不重试，调用方得到存储暂不可用错误

#### Scenario: 流式写入失败
- **WHEN** 远端媒体经流式写入 R2 时遇到服务暂不可用
- **THEN** 存储层不重试，由外层工作流步骤重试整个下载与写入
