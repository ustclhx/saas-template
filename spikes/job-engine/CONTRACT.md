# Local spike adapter contract (supervisor owned)
Only local prototypes; never commit. Independent npm deps fixed in this directory. Postgres host environment PGHOST=selfhost-b-spike-pg; PGDATABASE=dbos_spike or boss_spike; trust only on isolated Docker network, no published ports. PGUSER=postgres for migration; app for runtime. No connection strings/passwords in output.

Export async `makeAdapter({sql,workerId,handlers})` from dbos.mjs / boss.mjs. `sql` is postgres.js max=3. `handlers.workflow(params,step,id)` runs common workflow scenarios. `handlers.batch(messages)` handles actual batch of messages; messages `{id,queue,body,attempts,ack(),retry({delaySeconds})}`; await it then persist independent ack/retry, default unacked retry. Capture batch id/size in spike.batch table. Root creates spike schema / audit tables before adapter migration.
Adapter methods:
- migrate(): run library schema migrations using migrator; repeat safe. Do not use runtime DDL.
- start(): register handlers + start engine consumption. Runtime PGUSER=app with no CREATE/ALTER, not library default migrations.
- stop(): graceful stop.
- send({id,queue,body,delaySeconds=0}, tx?): id stable UUID; `main` default unbounded, `limited` concurrency 2 starts 3/10s across workers, `other` independent. Support array sendBatch(messages) with real batching 10/5 sec. May choose outbox; state exact implementation in report. Root outbox is shared publisher if direct tx impossible.
- create({id,params}): stable workflow ID, return id. get(id): `{status,output?,error?}` missing throws. status normalized queued/running/waiting/completed/failed/terminated.
- sendEvent(id,{type,payload}): reject missing/terminal, accepted persistent FIFO by type. terminate(id).
Step: `do(name, options?, callback)` retries `{limit,delayMs,backoff}` (limit excludes initial); timeoutMs; `sleep(name,durationMs)` durable; `waitForEvent(name,{type,timeoutMs})` returns `{type,payload,timestamp}` and throws name `WaitTimeoutError` on timeout. NonRetryableError detected by `error.name==='NonRetryableError'`, no retry.
Root audit schema will have `spike.calls(id bigserial, workflow_id text, step text, worker text, at timestamptz default now())`, `spike.effects(id text primary key, n int default 1)`, `spike.batch(id bigserial,worker text,size int,at timestamptz default now())`, `spike.message_attempt(id bigserial,message_id text,queue text,attempt int,worker text,started_at timestamptz default now(),ended_at timestamptz)`, `spike.dead_letter(message_id text primary key,queue text,attempts int,reason text,at timestamptz default now())`.
Queue retry policy 5 retries starting 30s doubling max900s; actual 6-attempt timestamps tested; DLQ written spike.dead_letter. handlers.batch calls explicit retry delay. Track calls in handlers so engine doesn't duplicate.
Use library's actual functionality; supplement missing features explicitly and report implementation complexity, don't label fabricated checks passed. No business source changes. Report npm fixed SHA/permission requirements and quick smoke command. No subagents. 10min task deadline; provide partial reliable adapter if blocked.
