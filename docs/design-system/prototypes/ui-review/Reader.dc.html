1. 摘要

本季度整体收入保持增长，但新客增长放缓。引导流程改版后留存改善明显；模型调用成本占比上升，是下季度需要优先处理的问题。

  • 新客增长低于预期，主要受渠道 B 投放收缩影响。
  • 次月留存提升，改版后的引导流程贡献最大。
  • 长文本请求占比提高，推高了单次调用成本。
