python 
def cac(spend: dict[str, float], new_users: dict[str, int]) -> dict[str, float]:
    # 新客为 0 的渠道不计算，避免除零
    return {ch: round(spend[ch] / n, 1) for ch, n in new_users.items() if n > 0}
  • 内容合作的 CAC 最低，且仍在小幅上升，适合加量；
