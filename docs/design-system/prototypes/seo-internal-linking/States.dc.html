组件变更提议（packages/ui 新增，需确认）

  • Breadcrumb：items: {label, href}[] 加 current；分隔符用 chevron 图标；caption 字号、muted-foreground；当前项 foreground 且不是链接；手机 < 768px 隐藏当前项。
  • Pagination：真实 <a href>，hrefFor(page) 由调用方给；当前页 primary 实底；首末页 + 当前前后各一；全部文案由调用方传入（上一页、下一页、页码 aria-label）。
  • LinkCard：标题（subtitle 字重 550）+ 可选一行说明（caption）；card 底、border 外框、radius-xl；用于相关文章与系列上一篇/下一篇。
  • LinkList：纯文字链接列表，桌面两列、手机单列（行高 ≥ 44px）；用于同组列表。
  • 不新增颜色、字号或圆角 token；全部取现有 background / card / border / muted-foreground / primary / primary-text。
  • 区块顺序：正文 → 系列上一篇/下一篇 → 相关文章 → 同组列表 → 页脚。面包屑替换现在文章顶部的「← 返回博客」链接。
