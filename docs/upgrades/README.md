# 模板升级说明

每个版本说明「上一模板版本 → 当前版本」的变化。跨版本升级时，按版本从低到高依次阅读，
逐项完成必须执行的动作，并遵守 `requiresDeployed` 声明的先部署边界。
例如从 0.2.0 升到 0.4.0，依次阅读 0.3.0 与 0.4.0 的说明。

模板通过 annotated tag `template-v<SemVer>` 按需发布，只创建 GitHub Release，不部署。
`v*` 用于模板演示站及衍生项目自身的生产发布，会触发生产部署，不代表模板版本。
版本号只记录在 tag 与升级说明中，不写入 `package.json`。
首个模板版本计划为 `template-v0.2.0`，其 `previous` 为历史起点 `v0.1.3`。

版本级别按衍生项目需要的动作决定：

- 1.0 之前：不兼容变更提升 MINOR，其他变更提升 PATCH。
- 1.0 及以后：不兼容变更提升 MAJOR，新功能提升 MINOR，纯修复提升 PATCH。
- 必须手动修改配置或代码、新增必填密钥/环境变量/部署绑定、删除或重命名能力及配置、
  收缩类数据库迁移均属于不兼容变更，说明中必须标记 `breaking: true`。
- 安全修复应尽快发布；其版本级别仍按上述兼容规则确定。

发布前从 [_template.md](_template.md) 起草说明，补全全部章节并更新下表。
索引按版本倒序维护；尚未发布的版本不得标为已发布。
