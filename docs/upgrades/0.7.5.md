## 概要

- 回退页校验测试从同站点选取另一种语言。没有同站点的另一种语言时跳过该用例。
- `mergeDevVars(base, overrides)` 合并 preview 变量时保留每个键的最后一次赋值。项目插件可用它添加或覆盖自动填充的变量。
- `template-sync.mjs sync` 支持用 `--branch <name>` 指定创建和续跑的同步分支。
- 多站点链接图报告保留总计，并按主机名列出页面数、链接数、最大点击深度和各规则命中数。JSON 使用 `sites` 字段。
