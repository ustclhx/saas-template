## 概要

修复 0.10.0 后台重新验证与待确认列表带来的三个问题（来自衍生项目同步反馈）：

- **入口包变大**：后台布局的 loader 与 `/admin/confirmations` 的 pendingComponent 不在 TanStack 默认的按路由拆包范围内，
  会把待确认列表、DataTable 与插件 server function 带进所有页面都下载的水合闭包。导航计数改为在 loader 中经 `import()`
  加载，待确认骨架移到不导入列表页的 `plugins/admin-mcp/src/web/confirmations-skeleton.tsx`。模板首页水合闭包 gzip
  由 321,911 B 降到 291,925 B。
- **首页包检查新增水合闭包检查**：`apps/web/scripts/check-home-bundle.mjs` 在水合闭包中发现 DataTable 时报出；
  设置了 `marketing.performance.homeScriptGzipBudget` 时构建失败，未设置时只警告。提示中给出改法：loader 里的重模块改用
  `import()`，骨架组件放在单独文件。
- **step-up 写 `verification` 表的项目扩展点**：新增项目自有文件
  `apps/web/src/features/admin/step-up/step-up.project.ts`。`stepUpVerificationColumns(userId, { db, request })` 返回写入
  验证码与失败计数行时追加的列（如多站点的必填 `site`，模板列优先），`stepUpEmailBrand(defaults, { db, request })`
  返回验证码邮件的应用名与站点地址。默认实现与 0.10.0 行为相同。`@saas/auth` 的 `createAdminStepUp` 新增可选依赖
  `verificationColumns`。
- **字号改用设计规范的字号角色**：重新验证弹窗、顶部警示条与 admin-mcp 插件页面（API 令牌、待确认列表、确认页）的
  `text-sm` / `text-xs` / `text-base` / `text-lg` 改为 `text-body` / `text-caption` / `text-title`。默认密度下
  只有确认页「未找到」标题由 18px 变为 16px，其余尺寸不变。

已在 0.10.0 中自行修补上述问题的衍生项目：同步时把 `verification` 附加列与邮件品牌的改动移到
`step-up.project.ts`，loader 与骨架的改动以模板为准即可。
