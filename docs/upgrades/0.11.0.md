## 概要

Studio 为 Cloudflare 与自托管 Node 项目提供图片或视频创作、作品库、公开画廊、举报与审核。它复用 Media 的模型、积分、任务与私有存储。模板默认启用，衍生项目升级时显式选择是否启用。后台模型可设置面向用户的显示名，未设置时沿用模型 key。[Studio 创作站](../06-ai.md#9-studio-创作站)

插件 Web 契约新增 `sitemaps` 与具名导出 `adminMcpTools`。管理员 MCP 工具表由内置工具和当前部署目标启用的插件工具合成。
Studio 声明 `/sitemap-gallery.xml`，同时启用 `admin-mcp` 时提供 `studio.works.list`、`studio.works.moderate`。
审核写工具支持 `dryRun`。`models.list` 返回 `displayName`，`models.update` 可修改或清除它。[插件扩展点](../plugins.md#扩展点) · [管理员 MCP 工具](../admin-mcp.md#工具与权限)

## 必须执行的动作

1. 部署前核对 `template.config.ts` 的 `plugins`。若 `.template-base.json` 未固定 `params.plugins`，且项目满足 Studio 的依赖，模板同步生成的目标版本可能带入 `studio: {}`。项目明确启用时保留或加入该键，并核对 `media`、计费、积分和所需的图片 / 视频 AI 开关。其余项目移除 `studio` 键。已有固定插件列表的项目沿用该选择。

## 配置变更

- `plugins.studio` 支持 `kinds`、`publishDailyLimit`、`reportHideThreshold`、`galleryPageSize` 与 `sites`。项目可在 `plugins/studio/src/studio.project.ts` 定义提示词预设，在 `plugins/studio/src/moderation.project.ts` 实现发布前检查。模板同步保留这两个文件的项目修改。
- Studio 复用现有媒体绑定。需要主动清除 Cloudflare 媒体缓存的部署可配 `CF_PURGE_TOKEN` 与 `CF_ZONE_ID`，匿名举报复用现有 Turnstile 配置。[Studio 公开媒体](../06-ai.md#studio-公开媒体) · [先发后审与举报](../06-ai.md#先发后审与举报)

## 数据库变更

### 0028_media_studio

- 类别：扩展
- 兼容上一版本代码：是
- 锁表与耗时：为 `ai_model` 加可空列时短暂持有表锁，新增外键会锁住被引用的表。新表为空，无历史数据回填，通常数秒内完成。锁等待上限 5 秒，单条语句上限 30 秒。
- 回滚：回退应用代码，保留表、索引、外键和列。

新增 `studio_work`、`studio_report` 及索引和约束，并新增 `ai_model.display_name`。

- 类别：扩展

- 锁表与耗时：新增外键时短暂锁住 `user` 表。新表为空，无历史数据回填，通常数秒内完成。锁等待上限 5 秒，单条语句上限 30 秒。

## 部署顺序

1. 合并配置与代码，并完成下方的本地检查。启用 Studio 时一并设置项目需要的模式和站点来源。
2. 在旧代码运行期间可依次应用 `0028_media_studio` 与 `0029_studio_publication_quota`。Cloudflare 按现有流程先迁移，再部署 jobs、web。自托管使用同一 SHA 的镜像组，由部署脚本先迁移再切换服务。

## 验证

- 运行 `pnpm check`、`pnpm typecheck`、`pnpm test`，按目标运行 `pnpm build` 或 `pnpm build:node`。
- 启用后在测试空间生成并发布一件作品，检查画廊可见、作品页带 `noindex`。审核通过后检查 `noindex` 消失，且作品加入画廊站点地图。撤回后从回源地址请求，确认作品页及旧媒体 URL 返回 404。视频另测单段 Range 返回 206。
- 用测试举报触发隐藏，在后台恢复后确认作品恢复可见。启用 `admin-mcp` 时核对工具权限和审核 `dryRun`。只启用图片模式时检查创作页和筛选项。停用 Studio 的项目检查页面返回 404，`robots.txt` 省略画廊站点地图。

## 回滚

- 移除 `plugins.studio` 并重新构建及部署可关闭 Studio，作品数据保留，应用继续使用本版本的清理逻辑。旧媒体与页面副本按缓存时限过期。[Studio 缓存时限](../06-ai.md#studio-公开媒体)
- 尚未产生作品时可回退应用代码，保留两条扩展迁移。已有作品时，优先保留本版本并停用 Studio。0.10.2 的清理任务无法识别仍被作品引用的文件和媒体任务，整体回退前须处理这些引用。
